# myFPV — симулятор fpv-дрона

## Запуск

Розпакувати й відкрити `index.html`. Локально працює як є (`file://`), на хостингу — просто
залити папку цілком. Жодних залежностей і збірки: three.js і nipplejs тягнуться з CDN.

```
index.html
assets/models.js       бібліотека 3d-моделей
assets/kyiv.json       офлайн-зліпок центру Києва (резерв, якщо OSM не відповів)
assets/keyboard.svg     карта керування на стартовому екрані
assets/favicon.svg
```

## Мапа

Реальна географія з OpenStreetMap за твоїми координатами (Overpass, усі дзеркала опитуються
одночасно). Чанки радіусом 500 м тягнуться ланцюгом уперед по траєкторії — до чотирьох попереду
на швидкості крила, мережа паралельно збірці. Якщо OSM недоступний — вантажиться `kyiv.json`
і місто продовжується процедурними тайлами по 420 м.

Щоб зробити свій офлайн-зліпок: злітай у потрібному районі й виконай у консолі `dumpMap()` —
завантажиться `kyiv.json`, поклади його в `assets/`.

## Керування

| клавіша | дія |
|---|---|
| `W` / `S` | тяга вгору / вниз |
| `A` / `D` | розворот |
| `P` / `;` | вперед / назад |
| `L` / `'` | знос вліво / вправо |
| `Space` | скид боєприпасу |
| `Shift` | пуск керованої ракети по захопленій цілі |
| `Z` · `T` · `N` | режим зору · тепловізор · ніч |
| `/` | вид від 1-ї особи ↔ зовнішній |
| `1` / `2` | fpv-коптер / крило |
| `3` `4` `5` | розвідник: розвідай / зависни / на базу |
| `−` / `=` | викликати приліт БР / гіперзвуку |
| `M` / `R` | геймпад: mode 1-2 · angle/acro |
| `U` · `G` · `Tab` | звук · режим польоту · безсмертя |

Повна карта клавіш — на стартовому екрані. Розкладка не має значення, читається фізична клавіша.

На тач-екрані — два стіки й шість кнопок-іконок: коптер/крило та безсмертя злива,
режим зору й виклик прильоту справа (іконка показує наступний тип: балістика ⇄ гіперзвук),
скид і пуск ракети — нижче, під великим пальцем. Кнопка ракети гасне, поки немає захвату;
на кнопці скиду риски показують залишок боєзапасу.

## Режими

Вільний політ · місії (5 типів із таймером) · тренування (без ППО, але з цивільним рухом) · аркада (хвилі).
Погода: ясно, вітер, дощ, туман, хмарність, сніг. Відеоканал: аналог, цифра, чисте відео.
Денна оптика 06:00–20:00 за годинником системи, далі нічна.

## Продуктивність

Щільність підлаштовується сама: просідання нижче 34 FPS зрізає її, стабільні 52+ повертають.
Індикатор внизу ліворуч: FPS · draw calls · будівель.
