# myFPV — симулятор fpv-дрона

## Запуск

Розпакувати й відкрити `index.html`. Локально працює як є (`file://`), на хостингу
(GitHub Pages: залити папку в репозиторій, Settings → Pages → deploy from branch) —
просто цілком. Жодної збірки: three.js і nipplejs тягнуться з CDN, решта вшита в
`index.html` (стартовий термінал, 3d-моделі, іконки).

```
index.html              гра + стартовий термінал (усе вшито)
assets/kyiv.json        офлайн-зліпок центру Києва (резерв, якщо OSM не відповів)
assets/keyboard.svg     карта клавіатури (мануал у терміналі та в грі)
assets/favicon.svg
assets/fonts/           SF Pro Text / Display / Mono для термінала (8 файлів)
```

## Мапа

Реальна географія з OpenStreetMap за координатами (Overpass, усі дзеркала опитуються
одночасно). Чанки радіусом 500 м тягнуться ланцюгом уперед по траєкторії. Якщо OSM
недоступний — вантажиться `assets/kyiv.json` і місто продовжується процедурними тайлами.

Свій офлайн-зліпок: злітай у потрібному районі, виконай у консолі `dumpMap()` —
завантажиться `kyiv.json`, поклади його в `assets/`.

## Стартовий термінал

Підготовка до вильоту за 5 кроків (район → борт → БЧ → умови → завдання),
ангар з 3d-моделями, мануал і налаштування. Утримання кнопки/пробілу — виліт.
Налаштування зберігаються в localStorage браузера.
