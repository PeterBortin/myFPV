# myFPV — модернизация 3D

## Файлы

| файл | что это |
|---|---|
| `models.js` | библиотека моделей. Геометрия строится один раз и шарится между инстансами. |
| `myFPV.html` | твой симулятор с интегрированными моделями, оптимизацией рендера и управлением с клавиатуры. |
| `models-preview.html` | стенд для осмотра моделей (вращать мышью, колесо — зум). Показывает draw calls каждой. |

Оба HTML грузят `models.js` из той же папки — положи рядом.

---

## 1. Модели

Ключевая замена: вместо `MeshBasicMaterial({wireframe:true})` — `EdgesGeometry` + `LineSegments`.
`wireframe:true` рисует все триангуляционные диагонали (та самая «грязь» по квадам); `EdgesGeometry`
оставляет только реальные рёбра. Пороговый угол убирает продольные линии на телах вращения:
цилиндр показывает два обода, а не 16 полос.

Все примитивы одной модели сливаются в **одну** `LineSegments` + опционально одну тёмную `Mesh`
(заливка, чтобы сквозь корпус не светились дальние линии; `polygonOffset` против z-fighting).

```js
const m = MODELS.quad({payload:true});   // {group, parts}
scene.add(m.group);
m.parts.props        // 4 объекта — крутить отдельно
m.parts.payload
```

| фабрика | draw calls | анимируемые части |
|---|---|---|
| `MODELS.quad({color,fill,scale,payload,blades})` | 2 + 4 пропа | `parts.props[]`, `parts.payload` |
| `MODELS.soldier(color)` | 6 близко / 1 далеко | `parts.legL/legR/armL/armR`, `parts.near/far` |
| `MODELS.tank(color)` | 6 | `parts.turret`, `parts.barrel` |
| `MODELS.wing({color,scale})` | 3 | `parts.props[]` |
| `MODELS.car(kind,color)` | 1 | — `kind`: `sedan` / `van` / `truck` |

Танк: башня доворачивается на дрон, ствол поднимается. Пехотинец: цикл ходьбы, руки в противофазу
с ногами; дальше 95 м подменяется одним слитым силуэтом.

## 2. Производительность

Было: каждое здание — группа из ~20 объектов, каждая дорога — своя `Line`, каждая машина —
свежая геометрия. Тысячи draw calls.

Стало: **~90 DC в плотном городе на 580 зданий, 60 FPS.**

- Весь чанк OSM сливается в 5 объектов: стены, крыши, рёбра, линии на земле, парки.
- `renderer.setPixelRatio(min(dpr, 1.5))` — на телефоне с dpr 3 это было 9× пикселей.
- Пространственная сетка зданий (70 м) вместо линейного перебора в коллизиях, prox-шуме и обходе препятствий.
- LOD/каллинг: далёкие цели не обновляются и не рисуются; пропы гаснут дальше 140 м.
- Мини-карта: статический слой (дороги + здания) печётся в offscreen-canvas и каждый кадр
  выводится одним `drawImage` со смещением; перепекается при загрузке чанка или сдвиге на ~1.5 км.
  Обновление 20 Гц, `shadowBlur` убран (он был самым дорогим в кадре).
- Prox-шум: 440×248 вместо полного экрана, через кадр, `ImageData` переиспользуется.
- Пул трассеров, общая геометрия партиклов, 4 заранее сгенерированных шумовых буфера на выстрелы
  (раньше буфер создавался на каждый) + лимит 3 выстрела на кадр.
- Сборка сцены уступает поток каждые 160 объектов — карта строится без фриза.

Индикатор внизу слева: `FPS · draw calls · зданий`.

## 3. Здания вместо чёрных кубов

Одна процедурная `CanvasTexture` 256×256 на весь город: сетка окон, часть светится.
UV считаются в реальном масштабе (этаж 3.3 м, панель 4.2 м), поэтому окна одного размера
на доме любой высоты. Плюс вершинные цвета: градиент от тёмного низа к светлому верху
и случайный оттенок на каждое здание, чтобы кварталы не выглядели штампованными.
Крыши — отдельный меш с плоским тёмным материалом.

Настройки — в `myFPV.html`: `FLOOR_H`, `PANEL_W`, `makeFacadeTex()`.

## 4. Управление с клавиатуры

Включается автоматически на десктопе (`pointer:coarse` → тач-режим, стики; иначе клавиатура,
стики скрыты, внизу подсказка — она уезжает через 20 с после старта). Тач имеет приоритет.

| клавиша | действие |
|---|---|
| `W` / `S` | тяга вверх / вниз |
| `A` / `D` | разворот влево / вправо |
| `[` / `]` | вперёд / назад |
| `;` / `'` | снос влево / вправо |

Стрелки работают как дубли (↑↓ тяга, ←→ снос). Отпустил `W`/`S` — тяга возвращается к
значению висения (`9.81 / PHYSICS.lift ≈ 0.19`), дрон держит высоту; без этого на бинарной
клавише полёт неуправляем. Все оси идут через плавный разгон.

Раскладка не важна — читается `e.code` (физическая клавиша).

## 5. Дорожная сеть и поведение объектов

Из OSM теперь тянутся и пешеходные типы (`footway`, `path`, `pedestrian`, `steps`, `track`),
каждый way получает класс: `trunk` / `avenue` / `street` / `lane` / `track` / `path` —
со своей скоростью, шириной, цветом в сцене и на мини-карте.

Точки всех way индексируются по координатам (`nodeMap`), из этого получается **граф**:
на перекрёстке объект выбирает следующий way, а не крутится по одной линии. Кто куда
допущен — в `roadOk()`: танк не лезет в `service`-проезды, гражданские не едут по `track`,
пехота ходит всюду включая тропы.

- **Танк:** `drive` → `halt` (башня сканирует сектор) → `drop` (десант выходит) →
  снова `drive` или `halt`. Переходы по случайному таймеру, поэтому колонна не
  выглядит закольцованной. Видит дрон ближе 430 м — башня ведёт его, ствол поднимается.
- **Машина:** `drive` ↔ `park`, тоже по таймеру. 46 машин на старте, потом по 18 на чанк.
- **Пехота:** при спавне строится маршрут по пешеходной сети (3–5 точек), солдат ходит по нему
  туда-назад с паузами (`hold` — стоит и озирается). Цикл ходьбы плавно затухает на остановке.
- **Квадрокоптеры:** `patrol` ↔ `hover` (висит на месте). **Крылья:** меняют скорость на дуге.

## 6. Помехи по типу источника

Три независимых источника, каждый со своим радиусом и своей картинкой:

| источник | радиус | эффект |
|---|---|---|
| стационарный — строения | 11 → 2 м | медленно ползущие горизонтальные полосы, холодный белый |
| ограниченно мобильный — люди | 16 → 3 м | мелкий зелёный «снег» |
| мобильный — техника, дроны | 27 → 6 м | блочные разрывы кадра, тряска, хроматическая аберрация, янтарно-красный |

Гражданские машины считаются мобильными, но глушат слабо (к дистанции прибавляется 11 м —
РЭБ на них нет). Цвет рамки берётся от доминирующего источника, так что по картинке видно,
что именно рядом. Всё рисуется в один canvas 440×248 через кадр + два CSS-слоя.

## 7. HUD

Мини-карта поднята к верху экрана, барабан курса над ней. Градиент радара крутится против
часовой. Блок «приоритет» убран — позывной вынесен по центру под карту. Срезанные углы убраны
со стартовой подложки и с плашки управления.
