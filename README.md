# myFPV — симулятор FPV-дрона

## GitHub Pages

1. Залити вміст цієї папки в корінь репозиторію (разом з `.nojekyll`).
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.

Збірка не потрібна: three.js і nipplejs тягнуться з CDN, решта вшита в `index.html`.
Локально теж працює — просто відкрити `index.html`.

```
index.html              гра + стартовий екран (усе вшито)
assets/kyiv.json        офлайн-зліпок центру Києва (резерв, якщо OSM не відповів)
assets/keyboard.svg     карта клавіатури
assets/favicon.svg
assets/fonts/           SF Pro Text / Display / Mono (8 файлів)
.nojekyll               вимикає обробку Jekyll на Pages
```

## Стартовий екран

Живий 3D-проліт над містом з обраним бортом у кадрі. Усе польотне завдання на одній
панелі: район, завдання, борт, БЧ, час доби, погода, відеоканал, складність.
Ангар з 3D-моделями, довідка з керування, системні налаштування. Виліт — кнопкою або Enter.
Налаштування зберігаються в localStorage браузера.

## Мапа

Реальна географія з OpenStreetMap за координатами. Якщо OSM недоступний — вантажиться
`assets/kyiv.json`, і місто продовжується процедурними тайлами.
Свій офлайн-зліпок: злітай у потрібному районі, виконай у консолі `dumpMap()`
і поклади отриманий `kyiv.json` в `assets/`.
